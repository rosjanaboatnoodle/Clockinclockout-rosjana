# ระบบตอกบัตรเข้า-ออกงาน

- `index.html` หน้าตอกบัตรของพนักงาน (เลือกชื่อ → ใส่ PIN → เข้างาน/ออกงาน) 6 ภาษา
- `admin.html` หน้าแอดมิน (พนักงาน + PIN, สาขา, ดูการตอกบัตร, ภาษา)
- `ui-text.js` ข้อความบนหน้าตอกบัตร (ต้นฉบับภาษาไทย)
- `supabase/` ฐานข้อมูล (`migrations/`) และโค้ดฝั่ง Supabase (`functions/clock/`)

ใช้ Supabase project เดียวกับปฏิทิน (Calendarsver2) ได้ พนักงาน สาขา คำแปล และรหัสแอดมินใช้ร่วมกัน
ถ้ามีปฏิทิน ข้อความของวันนั้น (เช่น เวรล้างห้องน้ำ) จะขึ้นหลังตอกเข้างาน และไฮไลต์เวรของคนนั้น

## ขั้นที่ทำแล้ว / ต่อไป

1. ✅ ตอกบัตร + PIN + พนักงานร่วมกับปฏิทิน + 6 ภาษา + ข้อความจากปฏิทิน
2. ✅ GPS (รัศมีตั้งได้ต่อสาขา) + ถ่ายรูป (เปิด/ปิดได้)
3. ✅ หน้าแอดมิน: แก้/เพิ่มเวลาเอง, ตั้งค่าเงิน (รายชั่วโมง/รายวัน) + โอที, รอบตัดบิล, เบิกเงิน
4. สรุปเงินรายรอบ (ตั้งรอบได้) + หักเงินเบิก + บิลเป็นรูป/PDF

## ติดตั้ง (มี Supabase project ของปฏิทินอยู่แล้ว)

1. Supabase → **SQL Editor** → วาง `supabase/migrations/0001_clock.sql` ทั้งไฟล์ → **Run**
   (ไม่กระทบข้อมูลปฏิทิน แค่เพิ่มช่อง PIN และตารางตอกบัตร)
   แล้วทำแบบเดียวกันกับ `0002_gps_photo.sql` (GPS + ที่เก็บรูป) และ `0003_pay.sql` (ค่าแรง โอที รอบ เบิกเงิน) ตามลำดับ
2. **Edge Functions** → **Deploy a new function** (ผ่าน Editor) → ตั้งชื่อ **`clock`** → วาง `supabase/functions/clock/index.ts` ทั้งไฟล์ → **Deploy**
3. ในหน้า function `clock` → แท็บ **Settings** → ปิด **Verify JWT with legacy secret** → Save
4. Secrets: `GEMINI_API_KEY` มีแล้วจากปฏิทิน (ใช้ร่วมกันทั้ง project) ไม่ต้องเพิ่ม
   ถ้าร้านไม่ได้อยู่เขตเวลาไทย เพิ่ม `TIMEZONE` เช่น `Asia/Yangon`
5. GitHub → repo นี้ → Settings → **Pages** → Deploy from a branch → เลือก branch → (root) → Save
6. เปิด `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/admin.html` → ใส่รหัสแอดมินเดียวกับปฏิทิน
   → แท็บ **พนักงาน**: ใส่ชื่อที่แสดง + PIN ให้ทุกคน → แท็บ **ภาษา**: กด **🌐 แปลส่วนที่ยังไม่แปล**
7. ส่งลิงก์ `index.html?branch=<รหัสสาขา>` ให้พนักงาน (ลิงก์ขึ้นในหน้าแอดมิน)

## ติดตั้งให้ร้านอื่น (ร้านละ Supabase + GitHub ของตัวเอง)

1. สร้าง Supabase project ใหม่ (Region: Singapore) และ copy repo นี้ไปไว้ใน GitHub ของร้านนั้น
2. ทำขั้นที่ 1–3 ด้านบน และเพิ่ม Secret `GEMINI_API_KEY` (สร้างที่ https://aistudio.google.com/apikey)
3. ใน `index.html` และ `admin.html` ใส่ `PROJECT_REF` (ส่วนหน้าของ Project URL) และ `SUPABASE_KEY`
   (Project Settings → API Keys → ตัวที่ขึ้นต้น `sb_publishable_`)
4. เปิด GitHub Pages แล้วเปิด `admin.html` ครั้งแรก จะมีหน้า **ตั้งค่าครั้งแรก** ให้ตั้งรหัสแอดมิน + สาขาแรก
5. เพิ่มพนักงาน + PIN แล้วกดแปลภาษา

## กติกาการตอกบัตร

- หนึ่งกะ = เข้างาน → ออกงาน นับเป็นวันที่ของเวลาเข้างาน (ข้ามเที่ยงคืนได้)
- กดเข้างานซ้ำตอนยังไม่ออก = ไม่บันทึกซ้ำ (กดพร้อมกันหลายครั้งก็ไม่ซ้ำ)
- ลืมตอกออก: ถ้ากะเดิมเปิดค้างเกิน 16 ชั่วโมง ตอนตอกเข้าครั้งถัดไประบบจะติดป้าย **ลืมตอกออก** ให้แอดมินแก้เวลา แล้วให้เข้างานใหม่ได้
- พนักงานที่ปิด "ใช้งานอยู่" จะไม่มีปุ่มให้ตอก (ประวัติเก่ายังอยู่)

## GPS และรูปถ่าย (ตั้งต่อสาขา ในหน้าแอดมิน → สาขา)

- **ตำแหน่งร้าน:** ยืนในร้านแล้วกด "ใช้ตำแหน่งตอนนี้" หรือวางพิกัดจาก Google Maps
- **รัศมี:** ค่าเริ่มต้น 50 ม. GPS มือถือคลาดเคลื่อนปกติ 5–20 ม. ในอาคารอาจถึง 30–50 ม. ตั้งแคบเกินไปคนที่อยู่ในร้านจะตอกไม่ผ่าน
- **บังคับ GPS:** หน้าตอกบัตรบอกระยะห่างสดๆ เซิร์ฟเวอร์เช็คซ้ำตอนบันทึก นอกรัศมีหรือสัญญาณอ่อนกว่า ±100 ม. จะไม่บันทึก
- **บังคับถ่ายรูป:** เปิดกล้องหน้า ย่อรูปในมือถือก่อนส่ง (~50–150 KB) เก็บในที่เก็บรูปแบบส่วนตัว ดูได้จากหน้าแอดมินเท่านั้น
- **ลบรูปอัตโนมัติ:** รูปที่เก่ากว่าจำนวนวันที่ตั้ง (ค่าเริ่มต้น 60 วัน) ถูกลบวันละครั้งตอนแอดมินเปิดหน้าการตอกบัตร
- หน้าแอดมิน → การตอกบัตร แสดงระยะห่างจากร้าน (สีแดง = นอกรัศมี) และรูปของทุกการตอก กดรูปเพื่อขยาย
- GPS ปลอมได้ด้วยแอปปลอมตำแหน่ง ถ้าต้องการยืนยันจริงจัง ใช้คู่กับการถ่ายรูป
- หน้าตอกบัตรมีข้อความแจ้งพนักงานว่าเก็บตำแหน่งและรูป (PDPA)

## ค่าแรง โอที รอบตัดบิล เบิกเงิน

**ตั้งครั้งเดียว ระบบคิดให้เองทุกวัน** งานแอดมินคือดูกล่อง "⚠️ ต้องตรวจ" แล้วออกบิลตอนสิ้นรอบ

- **ค่าเริ่มต้นของสาขา** (แท็บเงิน) ทุกคนใช้ค่านี้ **ตั้งแยกรายคน** ได้ (แท็บพนักงาน → 💰) ช่องว่าง = ใช้ค่าสาขา
- **รายวัน:** ค่าแรง/วัน, ชม.ปกติ/วัน, ทำไม่ถึง X ชม. = ครึ่งวัน, ไม่ถึง Y ชม. = ไม่นับวัน (อัตโนมัติ)
- **รายชั่วโมง:** ค่าแรง/ชม. (ชั่วโมงที่เป็นโอทีคิดด้วยอัตราโอทีแทน ไม่จ่ายซ้ำ)
- **โอที:** นับเมื่อ ทำเกิน X ชม./วัน หรือ ออกงานหลังเวลา Y หรือทั้งสองแบบ (ใช้ค่าที่มากกว่า ไม่บวกซ้ำ)
  ค่าโอที = ค่าแรงต่อชม. × ตัวคูณ (รายวันใช้ ค่าแรงวัน ÷ ชม.ปกติ) หรือ บาท/ชม. ตรงๆ
  ปัดลงทีละ N นาที และต้องเกินอย่างน้อย M นาทีถึงนับ
- **รอบตัดบิล:** รายเดือน (ตัดวันที่ X, 31 = สิ้นเดือน), เดือนละ 2 รอบ, ทุก N สัปดาห์ (ตัดวันไหน), ทุก N วัน
  ตั้งต่อสาขา หรือแยกรายคน ถ้ายังไม่เคยออกบิล มีผลทันที ถ้าเคยแล้ว มีผลรอบถัดไป
- **กล่อง "⚠️ ต้องตรวจ":** ลืมตอกออก, เปิดกะค้างเกิน 16 ชม., กะยาวเกิน 14 ชม., กะสั้นไม่ถึง 5 นาที
  กด "แก้" หรือ "ถูกต้องแล้ว" ส่วนวันที่ปกติไม่ต้องทำอะไร
- **แก้กะ / เพิ่มกะเอง:** แก้เวลาเข้า-ออก, ปรับวันทำงาน (เต็มวัน/ครึ่งวัน/ไม่นับ), ปรับนาทีโอที, ใส่หมายเหตุ ทุกการแก้มีบันทึกใน admin_log
- **เบิกเงิน:** แอดมินบันทึก (อนุมัติทันที) หรือพนักงานขอเองในหน้าตอกบัตร (ปุ่ม 💵 ใช้ PIN ตัวเอง)
  อนุมัติอัตโนมัติถ้าไม่เกิน X บาท (0 = ต้องอนุมัติทุกรายการ) แอดมินเพิ่มรายการซ้ำวันเดียวกับคำขอที่รออยู่ ระบบเตือนก่อน
- พนักงานเห็นยอดของตัวเองในรอบนี้: วันทำงาน, ชม.โอที, เบิกแล้ว, รออนุมัติ
- **รอบที่ออกบิลแล้วถูกล็อก** (ขั้นที่ 4) แก้เวลา/เบิกเงินในรอบนั้นไม่ได้
